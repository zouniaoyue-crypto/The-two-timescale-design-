PART B. [High - Logic/Derivation Error]
==================================================================================================

No item found. The modeling and solution chain is consistent: (P1) in (11) -> ZF-AN restriction
with long-term (p, q) (III-A, stated as a design choice) -> closed-form approximations (20), (27)
(III-B, III-C; validated in V-B) -> approximate problem (P3) -> alternating optimization with
Algorithm 1 for (p, q) and Algorithm 2 for t. The following steps were re-derived on the merged
text and are correct:
  - (12)-(15): ZF precoding and null-space AN, |h_m^H w̄_m|^2 = 1/[(H^H H)^{-1}]_{m,m},
    H^H P⊥ = 0, tr(P⊥) = N - M.
  - (20)-(21): eta_m(t) = zeta_m (N - M)/(N omega_m(t)); both bounds follow from Phi(t) ⪰ N I_M
    and [Phi^{-1}]_{m,m} >= 1/[Phi]_{m,m} = 1/(N(kappa_m + 1)), with equality for mutually
    orthogonal LoS components.
  - (22)-(27), Proposition 1, Appendix B: c_m, d in [0, N]; exactness for kappa_m = 0; the limit
    for growing Rician factors (H/sqrt(ϰ) -> L_0 almost surely, dominated convergence,
    N[Omega^2]_{m,m} = O(ϰ^{-2}) versus omega_m = O(ϰ^{-1})).
  - (32): high-SNR expansion; alpha* = 1/(1 + sqrt(Xi)) is the stationary point of
    log(alpha) + log(1 - alpha) - log(1 + alpha(Xi - 1)) (verified by substitution); Xi decreases
    when c_m decreases or d increases.
  - Remark 1 (new in v7): Sigma_dir = (N - M) q P⊥ ḡ ḡ^H P⊥ / Ȳ satisfies tr(Sigma_dir) =
    (N - M) q and H^H Sigma_dir = 0; E{g^H Sigma_dir g | H} = (N - M) q beta~_e (kappa_e Ȳ + 1);
    psi_dir - psi = (N - M - 1) kappa_e d >= 0.
  - Algorithm 2: the objective is nondecreasing because (41) includes the current position in the
    arg max (line 477) and the power update is accepted only if the objective does not decrease
    (IV-C); the upper bound in IV-C follows from (21).
