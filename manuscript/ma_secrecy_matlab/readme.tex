\section{概述}
% -----------------------------------------------------------------------------
本代码包（文件夹 \code{ma\_secrecy\_matlab}）复现稿件第 V 节的全部仿真结果：Fig.~3--Fig.~7、表~I，以及正文中只引用数字、不画图的结果。代码同时兼容 MATLAB（R2018b 及以上；导出矢量 PDF 推荐 R2020a 及以上）与 GNU Octave（$\ge 7$；本版结果用 Octave 8.4 算出），不需要任何工具箱，也不需要 CVX：
\begin{itemize}
\item 功率分配（算法~1）：保密注水（命题~3）+ 二分法 + 一维“粗网格 + 细网格”搜索；
\item 天线位置（算法~2）：逐天线更新，每根天线先在可移动区域的网格上做全局搜索（Stage~1，式 (45)），再做 MM 精修（Stage~2，式 (50)--(54)）；MM 子问题是二维凸 QP，用“枚举边与顶点”的方法精确求解；
\item 性能评估：所有方案都只用统计 CSI（闭式近似）做优化，然后在真实信道样本上用\textbf{精确的} ZF 预编码 + 零空间 AN（式 (12)、(13)）做蒙特卡洛评估，因此近似误差不会“美化”结果。
\end{itemize}

\textbf{仿真规模（默认）：}每个横轴点平均 100 个随机场景（LU 与 Eve 的 AoD，\code{numDrops}），所有方案共用同一批场景（配对比较）；每个设计用 5000 个信道样本做蒙特卡洛评估（\code{S}，Fig.~3 用 $10^4$）；算法~2 用 3 个初始化（UPA + 2 组随机位置）取最优。

\section{快速开始}
% -----------------------------------------------------------------------------
\begin{enumerate}
\item 把当前目录切换到 \code{ma\_secrecy\_matlab}。
\item \textbf{自检（约 1 分钟）：}
\begin{lstlisting}
check_implementation
\end{lstlisting}
输出：(1) 解析梯度与中心差分的相对误差（应 $<10^{-5}$），以及秩一快速计算 \code{objective\_F\_n} 与直接计算 \code{objective\_F} 的误差（应 $\approx10^{-14}$）；(2) 保密注水解的 KKT 检验；(3) 算法~2 的单调性；(4) 闭式速率与蒙特卡洛的对比。
\item \textbf{快速功能测试：}把 \code{run\_all.m} 中的 \code{QUICK = false;} 改为 \code{true} 后运行 \code{run\_all}（每点只用 3 个场景，几分钟跑完，曲线很粗糙，只用于检查代码能否运行）。
\item \textbf{完整仿真：}\code{QUICK = false;}（默认），运行 \code{run\_all}。实测耗时（Octave 8.4，4 核机器上 4 个会话并行，每个会话约占 1 个核）：Fig.~3 约 2 分钟，Fig.~4 约 45 分钟，Fig.~5（含 AS、稀疏 FPA、无 AN 方案与 TIN Eve 评估）约 100 分钟，Fig.~6 约 50 分钟，Fig.~7 两次运行（同质/异质 LU）各约 85--95 分钟；正文引用的结果：\code{extra\_eve\_aod\_error} 约 45 分钟，\code{extra\_as\_region} 约 20 分钟，\code{extra\_angle\_offset} 约 50 分钟，\code{extra\_single\_user} 约 15 分钟，\code{extra\_pa\_spread} 两次运行（0 dB、10 dB）各约 55--80 分钟。4 个会话并行时全部仿真约 2.7 小时；MATLAB 执行循环通常明显快于 Octave。想先快速看趋势，可把 \code{numDrops} 设为 20--30。
\item 各脚本互相独立，可以开多个 MATLAB 会话并行运行，例如
\begin{lstlisting}
prm = default_params();          % 读取默认参数
prm.numDrops = 30;               % 修改参数（这里减少场景数以加快速度）
fig5_snr(prm);                   % 只跑 Fig. 5（同时打印表 I）
fig7_power_allocation(prm, 0);   % Fig. 7 需要运行两次：同质 LU ...
fig7_power_allocation(prm, 20);  % ... 与异质 LU（衰落差异 20 dB），都完成后自动画图
\end{lstlisting}
\item 结果保存在 \code{results/}：\code{.mat} 数据与图。MATLAB 下每张图导出矢量 \code{.pdf}（嵌入字体，稿件优先引用）、\code{.eps}、600 dpi \code{.png} 与 \code{.fig}；Octave 下只导出 600 dpi \code{.png}（Octave 的矢量导出会压缩词间空格，图例符号也不随尺寸缩放）。只想重画图时运行 \code{replot\_all}；Octave 需要 qt 图形工具包，无显示器时用 \code{xvfb-run -a octave --no-gui --eval replot\_all}。
\end{enumerate}

\subsection{\code{functions/}：优化算法}
\begin{longtable}{>{\ttfamily\small}p{4.6cm}p{11.2cm}}
\toprule
secrecy\_wf.m & 保密注水（命题~3，式 (37)）：对网格上所有 $q$ 同时二分求水位 $\nu$（向量化）。\\
power\_opt.m & 算法~1：固定位置下的功率分配。模式 \code{'full'}（所提：注水 + 搜索 $q$）、\code{'noan'}（$q=0$）、\code{'epa'}（等功率 + 搜索 $\alpha$）、\code{'fix'}（等功率 + 固定 $\alpha$）。\\
position\_sweep.m & 一轮逐天线位置更新（第 IV-C 节）。对每根天线：\textbf{Stage 1} 在间距 \code{gridStep} 的网格中满足最小间距的点上调用 \code{objective\_F\_n}，取最优（候选集合包含当前位置，因此目标值不下降，式 (45)）；\textbf{Stage 2} 从该点出发做至多 \code{mmMaxIter} 次 MM 迭代（梯度 \code{grad\_F\_n}、二次下界 (50)、线性化约束 (52)、投影 \code{proj\_polygon}、回溯 $\delta_n\leftarrow2\delta_n$），相对增量小于 \code{mmTol} 时停止。\code{gridStep = 0} 时跳过 Stage 1（即纯 MM，Fig.~4 中的 “MM only”）。\\
lin\_constraints.m & 子问题 (53) 的线性约束：区域盒约束 + 线性化最小间距（式 (52)）。\\
proj\_polygon.m & 二维凸 QP 的精确解（点到凸多边形的投影：枚举各约束线上的投影与两两交点）。\\
ao\_optimize.m & 算法~2：\code{position\_sweep} 与 \code{power\_opt} 交替迭代；新功率分配只在目标值不下降时接受；相对增量小于 \code{aoTol} 或达到 \code{aoMaxIter} 时停止。返回位置、功率与目标值历史 \code{hist}。\\
rate\_oriented\_positions.m & 基准“速率导向 MA”：最大化 LU 的近似遍历和速率（等功率、忽略 Eve，即令 $\kappa_e=0$、$q=0$），使用与所提方案\textbf{相同}的位置更新与初始化（公平比较）。\\
as\_select.m & 基准“天线选择（AS）”：对全部 $\binom{2N}{N}=12870$ 个子集用统计 CSI 计算近似 ESSR（与所提方案相同的目标），按子集向量化；可传入其他候选位置（如铺满区域的 UPA）。\\
\bottomrule
\end{longtable}

\subsection{算法 2（\code{ao\_optimize.m}）的内部逻辑}
\begin{enumerate}
\item 初始化位置 $\bt^{(0)}$（UPA 或随机可行位置），调用 \code{power\_opt} 得到 $(\mathbf p^{(0)},q^{(0)})$。
\item \textbf{位置更新}（\code{position\_sweep}），对 $n=1,\dots,N$：
  \begin{enumerate}
  \item \textbf{Stage 1（全局搜索）：}生成间距 \code{gridStep} 的网格，去掉与其他天线距离小于 $D_{\min}$ 的点，再加入当前位置；\code{objective\_F\_n} 一次性计算所有候选点的 $F$，取最大者（式 (45)）。
  \item \textbf{Stage 2（MM 精修）：}\code{grad\_F\_n} 计算梯度（式 (49)）；\code{lin\_constraints} 生成盒约束与线性化间距约束（式 (52)）；\code{proj\_polygon} 把 $\bt_n+\nabla F/\delta_n$ 投影到凸多边形（式 (53)）；若新点不满足 $F\ge$ 二次下界（式 (50)）则 $\delta_n\leftarrow2\delta_n$ 重新求解。重复至相对增量 $<$ \code{mmTol} 或 \code{mmMaxIter} 次。
  \end{enumerate}
\item \textbf{功率更新}（\code{power\_opt}，算法~1）：对 $q$ 做“粗网格 + 细网格”搜索，每个 $q$ 下用保密注水得到 $\mathbf p$；只有目标值不下降时才接受。
\item 若相对增量 $<$ \code{aoTol}，或达到 \code{aoMaxIter}，停止；否则回到第 2 步。
\end{enumerate}
每一步都不降低 $F$，所以目标值序列单调不减（\code{check\_implementation} 与 Fig.~4 可以验证）。

\textbf{为什么需要 Stage 1：}$F$ 关于 $\bt_n$ 含相位 $\frac{2\pi}{\lambda}\bt_n^T(\mathbf a_j-\mathbf a_i)$，周期约为 $\lambda/\|\mathbf a_j-\mathbf a_i\|$（本文参数下不小于约 $0.38\lambda$），因此 $F(\bt_n)$ 有大量局部极大值。纯 MM 只能爬到离当前位置最近的局部极大值，天线在区域内“挪动”得很慢（Fig.~4 的 “MM only” 曲线需要几十次迭代且终值更低）。Stage 1 用 $\lambda/10$ 的网格（每个周期至少 3--4 个点）直接找到最好的“山头”，Stage 2 再在山头内精确爬升，因此通常几次迭代就收敛。

\textbf{等功率基准（\code{'epa'}, \code{'fix'}）：}等功率时不能关断保密速率为负的 LU，命题~2 不成立，目标取 $\sum_m[\tilde R_m-\tilde R_{e,m}]^+$。Stage 1 直接计算该目标；Stage 2 只对当前保密速率为正的 LU 求梯度（$\sum_{m:\,f_m>0}f_m$ 是 $\sum_m[f_m]^+$ 的下界且在当前点相等），因此单调性仍成立。

\subsection{保密注水（\code{secrecy\_wf.m}）}
给定 $q$，令 $\eta_{e,m}=\xi_m/(q\psi+\bar\sigma_e^2)$。$\eta_m\le\eta_{e,m}$ 的 LU 直接关断；其余 LU 按式 (37) 计算 $p_m(\nu)$，$\sum_mp_m(\nu)$ 关于 $\nu$ 单调递减，用二分法使之等于 $\Ptot-(N-M)q$。代码对网格上所有 $q$ 同时二分（向量化）。

\subsection{蒙特卡洛评估（\code{mc\_rates.m}）}
每个样本生成 $\mathbf H=(\mathbf L+\tilde{\mathbf H})\mathbf B^{1/2}$ 与 $\mathbf g$，计算 $\mathbf G=\mathbf H^H\mathbf H$、$\mathbf u=\mathbf H^H\mathbf g$ 与 $\mathbf G^{-1}$，然后
\[
\gamma_m=\frac{p_m}{\sigma_m^2[\mathbf G^{-1}]_{m,m}},\quad
|\mathbf g^H\bar{\mathbf w}_m|^2=\frac{|[\mathbf u^H\mathbf G^{-1}]_m|^2}{[\mathbf G^{-1}]_{m,m}},\quad
\mathbf g^H\mathbf P_{\mathbf H}^\perp\mathbf g=\|\mathbf g\|^2-\mathbf u^H\mathbf G^{-1}\mathbf u,
\]
即式 (12)、(13) 的精确值。ESSR $=\sum_m[\bar R_m-\bar R_{e,m}]^+$。TIN Eve（式 (55)）用同一批样本计算。所有方案都按最坏情况 Eve 优化，TIN 只用于评估。

\section{常见修改}
% -----------------------------------------------------------------------------
\begin{itemize}
\item \textbf{改系统参数：}
\begin{lstlisting}
prm = default_params();  prm.N = 6;  prm.kappa_dB = 5;
fig5_snr(prm);
\end{lstlisting}
\item \textbf{不同用户不同路损：}\code{prm.beta\_dB = [0 -10 -20];}（长度须等于 $M$）。
\item \textbf{Eve 的 AoD 误差：}\code{prm.eveAoDErr = 0.02;}（rad），之后任何脚本都用有误差的 Eve AoD 设计、用真实 AoD 评估。
\item \textbf{改扫描范围：}修改对应脚本中 \code{sweep\_schemes} 的取值向量。
\item \textbf{改位置算法：}网格间距 \code{prm.gridStep}（越小越精细、越慢；0 表示纯 MM）、MM 次数 \code{prm.mmMaxIter}、停止阈值 \code{prm.aoTol}。注意区域变大时网格点数按 $(A/{\tt gridStep}+1)^2$ 增长。
\item \textbf{加一个新方案：}(1) 在 \code{evaluate\_schemes.m} 的 \code{switch} 中加一个 \code{case}，给出位置 \code{T} 与功率 \code{p}, \code{q}；(2) 在 \code{scheme\_style.m} 中加图例名、颜色、线型、标记；(3) 若要画进 Fig.~5/6，把方案名加入 \code{main\_schemes.m}。
\item \textbf{加一张新图：}复制一个 \code{figX\_*.m}（调用 \code{sweep\_schemes} 并保存 \code{.mat}）和对应的 \code{plot\_figX.m}（用 \code{new\_figure}、\code{plot\_schemes}、\code{label\_axes}、\code{add\_legend}、\code{save\_figure}），样式自动与其他图一致。
\item \textbf{加速：}减小 \code{numDrops}、\code{S}、\code{numInit}；或在 \code{sweep\_schemes.m} 中把场景循环改为 \code{parfor}（需要 Parallel Computing Toolbox，并把循环内的累加改为先存入数组、循环后再求平均）。
\item \textbf{只重画图：}\code{replot\_all}。改整体风格时只需修改 \code{fig\_style.m} 与 \code{scheme\_style.m}。
\item \textbf{Octave：}需要 qt 图形工具包；无显示器时用 \code{xvfb-run -a octave --no-gui}；若出现 \code{ft\_text\_renderer: invalid bounding box}，安装 \code{fonts-freefont-otf}。
\end{itemize}

\section{已完成的正确性检验}
% -----------------------------------------------------------------------------
\begin{itemize}
\item 解析梯度（含附录 B 的 $\dot d$）与中心差分的最大相对误差约 $1.3\times10^{-7}$（等功率模式下的部分梯度约 $1.2\times10^{-7}$）；

\item 保密注水解满足 KKT 条件（活跃用户边际收益相等、功率用满、关断用户满足 $f_m'(0)\le\nu$）；
\item 算法~2 在 \code{'full'}、\code{'epa'}、\code{'fix'} 模式下单调不减；
\item 全局搜索 + MM 与纯 MM 的对比（\code{fig4\_convergence}，100 个场景，$N=8$，20 dB）：终值平均高 4.2\%（95 个场景更好），平均曲线达到 95\% 改进所需迭代次数从 32 次降到 2 次；两组随机初始化与 UPA 初始化的终值平均只差约 0.1\%；预实验中网格间距 $\lambda/20$ 与 $\lambda/10$ 的结果相同；
\item AS 的向量化选择与逐子集标量实现一致（相对误差约 $10^{-15}$）；
\item \code{run\_all} 在 \code{QUICK} 模式下完整运行无报错。
\end{itemize}
