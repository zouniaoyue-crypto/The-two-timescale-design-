\section{概述}
本代码包复现 \code{main.tex} 第 V 节的全部仿真（Fig.~3--Fig.~8），包括：
\begin{enumerate}
\item 闭式近似的精度验证（LU 遍历速率：引理 1，式 (17)；Eve 遍历窃听速率：命题 1，式 (26)）；
\item 算法 2（交替优化 AO）的收敛性；
\item 遍历保密和速率（ESSR）随发射信噪比、Eve 与 LU 1 的角度偏差 $\Delta$、可移动区域边长 $A$ 的变化，以及最优 AN 功率占比（AN 节省效应，注 4）和单用户情形（注 3）；对比方案包括速率导向 MA、天线选择（AS）、稀疏 FPA 与紧凑 FPA；
\item 两种 Eve 模型（最坏情况 Eve 与“把其他 LU 信号当噪声”的 TIN Eve）下的 ESSR（稿件表 II，含无 AN 方案）；
\item 长时功率分配（每用户保密注水 + AN 功率优化）相对两种等功率方案的收益随 LU 大尺度衰落差异 $\varsigma$ 的变化（Fig.~8：0 dB 与 10 dB 两个子图；20 dB 的结果在正文中引用）。
\end{enumerate}
所有优化只使用统计 CSI（式 (17)、(26) 的闭式近似）；所有性能曲线（除 Fig.~3 的 closed-form 曲线外）均用\textbf{精确的} ZF 预编码 + 零空间 AN（式 (12)、(13)）做蒙特卡洛评估。
代码不依赖任何工具箱（不需要 CVX）：功率分配用二分法 + 一维网格搜索，位置子问题 (52) 是二维凸 QP，用“枚举边与顶点”的方法精确求解。

\textbf{运行环境：} MATLAB R2018b 及以上（导出矢量 PDF 推荐 R2020a 及以上，会自动使用 \code{exportgraphics}），或 GNU Octave $\ge$ 7（本次全部结果用 Octave 8.4 算出）。

\section{快速开始}
\begin{enumerate}
\item 在 MATLAB 中把当前目录切换到 \code{ma\_secrecy\_matlab}。
\item \textbf{自检（约 1 分钟）：}
\begin{lstlisting}
check_implementation
\end{lstlisting}
它会输出：解析梯度与有限差分的相对误差（应 $<10^{-5}$）、保密注水解的 KKT 检验、算法 2 的单调性、闭式速率与蒙特卡洛的对比。
\item \textbf{快速功能测试：}打开 \code{run\_all.m}，把第一行改为 \code{QUICK = true;} 后运行（每个点只用 3 个随机场景，几分钟内跑完，曲线较粗糙）。
\item \textbf{完整仿真：}\code{QUICK = false;}（默认），运行 \code{run\_all}。默认每个点平均 100 个随机场景（\code{numDrops}）。
实测耗时（Octave 8.4，4 核机器上 4 个脚本并行、每个约占 1 个核，每点 100 个场景）：Fig.~3 约 2 分钟，Fig.~4 约 1 分钟，Fig.~5 约 110 分钟（含 AS、无 AN 与 TIN 评估），Fig.~6(a) 约 100 分钟，Fig.~6(b) 约 40 分钟，Fig.~7 约 100 分钟，Fig.~8 三次运行（0/10/20 dB）各约 50--90 分钟；折合单线程共约 9--10 小时。AS 基准每个场景约 2 s（$\binom{16}{8}=12870$ 个子集，向量化）。MATLAB 执行循环通常明显快于 Octave。想先快速看趋势，可把 \code{numDrops} 设为 20--30。
各脚本互相独立，可以多开几个 MATLAB 会话并行运行，例如
\begin{lstlisting}
prm = default_params();         % 读取默认参数
prm.numDrops = 30;              % 修改参数（这里减少随机场景数以加快速度）
fig5_snr(prm);                  % 只跑 Fig. 5（同时生成 (a) ESSR 与 (b) AN 功率占比）
fig8_power_allocation(prm, 0);  % Fig. 8 需要运行两次：(a) P_tot/sigma^2 = 0 dB ...
fig8_power_allocation(prm, 10); % ... 与 (b) 10 dB（prm.fig8SNR），两次都完成后自动画图
fig8_power_allocation(prm, 20); % 可选：20 dB 的结果只在正文中引用
\end{lstlisting}
\item 结果保存在 \code{results/} 文件夹：\code{.mat}（数据）以及图。MATLAB 下每张图导出矢量 \code{.pdf}（嵌入字体，稿件直接引用）、\code{.eps}、600 dpi \code{.png} 与 \code{.fig}；Octave 下只导出 600 dpi \code{.png}（Octave 的矢量导出在小字号下字符间距不准）。
只想重画图（不重新仿真）时运行 \code{replot\_all}。
\end{enumerate}

\subsection{算法 2（\code{ao\_optimize.m}）的内部逻辑}
\begin{enumerate}
\item 初始化位置 $\bt^{(0)}$（UPA 或随机可行位置），调用 \code{power\_opt} 得到 $(\mathbf p^{(0)},q^{(0)})$。
\item \textbf{位置更新}（\code{position\_sweep}）：对 $n=1,\dots,N$：
  \begin{enumerate}
  \item \code{grad\_F\_n} 计算 $\nabla_{\bt_n}F$（式 (48)）；
  \item \code{lin\_constraints} 生成 $\mathcal C$ 的盒约束和线性化间距约束 (51)；
  \item \code{proj\_polygon} 求解子问题 (52)：把 $\bt_n^{(\ell)}+\nabla F/\delta_n$ 投影到凸多边形；
  \item 回溯：若 $F(\text{新点})<\hat F_n(\text{新点})$（式 (49) 的二次下界），则 $\delta_n\leftarrow2\delta_n$ 重新求解；满足后接受新点（保证式 (53) 的单调性）。
  \end{enumerate}
\item \textbf{功率更新}（\code{power\_opt}，算法 1）：对 $q$ 做“粗网格 + 细网格”一维搜索，每个 $q$ 下用 \code{secrecy\_wf} 的保密注水 (38) 得到 $\mathbf p$；只有当目标值不下降时才接受新的 $(\mathbf p,q)$。
\item 若目标值的相对增量小于 \code{aoTol}，或达到 \code{aoMaxIter}，停止；否则回到第 2 步。
\end{enumerate}
由于每一步都不降低 $F$，目标值序列单调不减（Fig.~4 可以验证）。

\textbf{等功率基准（\code{'epa'}, \code{'fix'}）的区别：}等功率时无法关断保密速率为负的 LU，命题 2 不成立，因此目标取 $\sum_m[\tilde R_m-\tilde R_{e,m}]^+$。
位置更新时只对当前保密速率为正的 LU 求梯度：$\sum_{m:\,f_m>0}f_m$ 是 $\sum_m[f_m]^+$ 的下界且在当前点处相等，所以 MM 的单调性仍然成立。

\subsection{保密注水（\code{secrecy\_wf.m}）}
给定 $q$，令 $\eta_{e,m}=\xi_m/(q\psi+\bar\sigma_e^2)$（Eve 的等效增益）。$\eta_m\le\eta_{e,m}$ 的 LU 直接关断（$p_m=0$）；其余 LU 按式 (38)
\[
p_m(\nu)=\Big[\tfrac{2(\rho_m-1)}{\sqrt{(\eta_m-\eta_{e,m})^2+4\eta_m\eta_{e,m}\rho_m}+\eta_m+\eta_{e,m}}\Big]^+,\quad \rho_m=\tfrac{\eta_m-\eta_{e,m}}{\nu\ln2},
\]
$\sum_mp_m(\nu)$ 关于 $\nu$ 单调递减，用二分法使之等于 $P_{\rm I}(q)=P_{\rm tot}-(N-M)q$。代码对网格上的所有 $q$ 同时二分（向量化），速度很快。

\subsection{蒙特卡洛评估（\code{mc\_rates.m}）}
每个样本生成 $\mathbf H=(\mathbf L+\tilde{\mathbf H})\mathbf B^{1/2}$ 与 $\mathbf g$，计算 $\mathbf G=\mathbf H^H\mathbf H$、$\mathbf u=\mathbf H^H\mathbf g$ 和 $\mathbf G^{-1}$（批量求逆），然后
\[
\gamma_m=\frac{p_m}{\sigma_m^2[\mathbf G^{-1}]_{m,m}},\quad
|\mathbf g^H\bar{\mathbf w}_m|^2=\frac{|[\mathbf u^H\mathbf G^{-1}]_m|^2}{[\mathbf G^{-1}]_{m,m}},\quad
\mathbf g^H\mathbf P_{\mathbf H}^\perp\mathbf g=\|\mathbf g\|^2-\mathbf u^H\mathbf G^{-1}\mathbf u,
\]
即式 (12)、(13) 的精确值（不需要显式构造 $N\times N$ 投影矩阵）。ESSR $=\sum_m[\bar R_m-\bar R_{e,m}]^+$。

TIN Eve（表 II）：Eve 不消除其他 LU 的信号，第 $m$ 路的 SINR 为
\[
\gamma_{e,m}^{\rm TIN}=\frac{p_m|\mathbf g^H\bar{\mathbf w}_m|^2}{\sum_{j\ne m}p_j|\mathbf g^H\bar{\mathbf w}_j|^2+q\,\mathbf g^H\mathbf P_{\mathbf H}^\perp\mathbf g+\sigma_e^2},
\]
用同一批信道样本计算（代码中 \code{rx}、\code{itf}）。注意所有方案都是按最坏情况 Eve 优化的，TIN 只用于评估“设计对 Eve 模型的鲁棒性”。

\section{各图说明与预期现象}
\begin{description}
\item[Fig.~3（\code{fig3\_accuracy}）] 固定功率分割 $\alpha=0.5$，紧凑 UPA 与随机 MA 位置两种布局；(a) 横轴为发射 SNR，(b) 横轴为莱斯因子 $\kappa=\kappa_e$。上面一组曲线是 LU 的遍历和速率（引理 1），下面一组是 Eve 的遍历窃听和速率（命题 1）；标记为蒙特卡洛，线为闭式。
预期：Eve 的闭式近似与蒙特卡洛高度吻合；LU 的闭式近似（现有结果）偏保守，差距随 $\kappa$ 增大，但两种布局几乎相同（支撑注 1：对位置优化影响很小）。
\item[Fig.~4（\code{fig4\_convergence}）] 算法 2 的目标值随迭代单调上升并收敛；不同初始化收敛到相近的值；命令行同时打印最终解的蒙特卡洛 ESSR。
\item[Fig.~5（\code{fig5\_snr}）] (a) ESSR 与 (b) AN 功率占比 $(N-M)q/P_{\rm tot}$ 随发射 SNR 的变化，5 种方案。预期：所提方案最好；速率导向 MA 与稀疏 FPA 相近（只考虑 LU 去相关、不考虑 Eve 的位置对保密帮助有限）；AS 比紧凑 FPA 好，但受限于 $\lambda/2$ 网格与小孔径；所提方案的 AN 占比明显低于所有基准，而速率导向 MA 的 AN 占比与紧凑 FPA 几乎相同（AN 节省来自“针对 Eve 的位置设计”，注 4）。同一次运行还计算无 AN 方案与 TIN Eve 下的 ESSR，并打印表 II：无 AN 方案只在最坏情况 Eve 下高 SNR 饱和，在 TIN Eve 下随 SNR 增长；所提方案在两种模型下都最好。
\item[Fig.~6（\code{fig6a\_angle}, \code{fig6b\_single\_user}）] ESSR 随 $\Delta$ 的变化（横轴对数刻度）。(a) $M=3$：$\Delta$ 很小时任何阵列都难以区分 Eve 与 LU 1，各方案接近；中等 $\Delta$ 时所提方案增益最大；$\Delta$ 很大时 Eve 本身容易分开，速率导向 MA 追上一部分。(b) $M=1$：LU 的速率与位置无关（注 3），速率导向 MA 保持初始 UPA，与紧凑 FPA 完全重合；所提方案仍有显著增益；AS 随 $\Delta$ 增大而改善，$\Delta=0.5$ rad 时接近所提方案。
\item[Fig.~7（\code{fig7\_region}）] ESSR 随区域边长 $A$ 增大而增大；紧凑 FPA 与 AS 与 $A$ 无关（AS 的候选阵列是 $1.5\lambda\times1.5\lambda$ 的 $4\times4$ UPA，$A=1.5\lambda$ 时与所提方案相当，$A\ge2\lambda$ 后被超过）；速率导向 MA 随 $A$ 改善很少；稀疏 FPA 随阵元间距变化而起伏（栅瓣位置相对 Eve 变化）。
\item[Fig.~8（\code{fig8\_power\_allocation}）] 横轴为 LU 大尺度衰落的差异 $\varsigma$（$[\beta_1,\beta_2,\beta_3]=[0,-\varsigma/2,-\varsigma]$ dB，$\varsigma=0$ 即前面各图的同质 LU），纵轴为 ESSR（绝对值，不再画“损失百分比”）；(a) 0 dB，(b) 10 dB。红色圆圈：所提功率分配；蓝色方块：等功率 + 优化 $\alpha$；灰色三角：等功率 + $\alpha=0.5$。位置均由算法 2 针对各自的功率分配优化。
预期：$\varsigma$ 较小时“等功率 + 优化 $\alpha$”接近最优（用户近似对称，注水趋于等功率）；当最弱 LU 的等效增益接近 Eve 时（0 dB 下约 $\varsigma\ge10$ dB，10 dB 下约 $\varsigma\ge15$ dB），所提功率分配将其关断或降功率，优势明显增大；20 dB 时所有 LU 都有正的保密速率，优势消失（因此不作为子图）；固定 $\alpha=0.5$ 始终最差，低 SNR 时最严重。具体数字见稿件第 V-G 节。
\end{description}

\section{绘图风格（IEEE 期刊常见格式）}
\begin{itemize}
\item 每个子图按单栏宽度 3.5 in $\times$ 2.6 in 导出，插入稿件时（\code{\textbackslash columnwidth} 或 \code{0.48\textbackslash textwidth}）字号即为实际字号：刻度 8 pt、坐标轴标签 9 pt、图例 7.5 pt，字体 Times New Roman（与 IEEEtran 正文一致）。
\item 同一方案在所有图中颜色、线型、标记固定（\code{scheme\_style.m}）：MA 类方案实线，FPA 类方案虚线，AS 点划线（橙色倒三角）；空心标记（白色填充）。
\item 细虚线网格、刻度朝内、坐标框在曲线之上；图例放在空白区域，必要时双栏或“分解式”图例（颜色 = 方案，线型 = 参数）。
\item 想整体改风格（如字体、线宽、配色）时只需修改 \code{fig\_style.m} 与 \code{scheme\_style.m}，然后运行 \code{replot\_all}。
\end{itemize}

\section{常见修改}
\begin{itemize}
\item \textbf{改系统参数：}例如
\begin{lstlisting}
prm = default_params();  prm.N = 6;  prm.kappa_dB = 5;
fig5_snr(prm);
\end{lstlisting}
\item \textbf{不同用户不同路损：}\code{prm.beta\_dB = [0 -10 -20];}（长度须等于 $M$）。用户差异大、SNR 较低时，每用户功率分配相对等功率的增益更明显（见 Fig.~8）。
\item \textbf{改扫描范围：}在对应 \code{figX\_*.m} 中修改 \code{sweep\_schemes} 的取值向量。
\item \textbf{加速：}减小 \code{numDrops}、\code{S}、\code{numInit}；或在 \code{sweep\_schemes.m} 中把随机场景循环改为 \code{parfor}（需要 Parallel Computing Toolbox，并把循环内的累加改为先存入数组、循环结束后再求平均）。
\item \textbf{只重画图：}运行 \code{replot\_all}（读取 \code{results/*.mat}）。
\item \textbf{Octave 用户：}需要 qt 图形工具包才能得到与 MATLAB 接近的图；无显示器的服务器上可用 \code{xvfb-run -a octave --no-gui}，并在脚本开头执行 \code{graphics\_toolkit('qt')}。
\end{itemize}
