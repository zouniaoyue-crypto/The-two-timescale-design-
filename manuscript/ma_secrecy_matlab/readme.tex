\section{概述}
本代码包复现 \code{main.tex} 第 V 节的关键仿真，包括：
\begin{enumerate}
\item 闭式近似的精度验证（LU 遍历速率：引理 1，式 (17)；Eve 遍历窃听速率：命题 1，式 (26)）；
\item 算法 2（交替优化 AO）的收敛性；
\item 遍历保密和速率（ESSR）随发射信噪比、Eve 与 LU 1 的角度偏差 $\Delta$、可移动区域边长 $A$ 的变化；
\item 最优 AN 功率占比（AN 节省效应，注 4）以及单用户情形（注 3）。
\end{enumerate}
所有优化只使用统计 CSI（式 (17)、(26) 的闭式近似）；所有性能曲线（除图 1 的“closed form”曲线外）均用\textbf{精确的} ZF 预编码 + 零空间 AN（式 (12)、(13)）进行蒙特卡洛评估。
代码不依赖任何工具箱（不需要 CVX）：功率分配用二分法 + 一维网格搜索，位置子问题 (52) 是二维凸 QP，用“枚举边与顶点”的方法精确求解。

\textbf{运行环境：} MATLAB R2018b 及以上（已按 MATLAB 语法编写），或 GNU Octave $\ge$ 7（作者用 Octave 8.4 实测通过全部脚本）。

\section{快速开始}
\begin{enumerate}
\item 在 MATLAB 中把当前目录切换到 \code{ma\_secrecy\_matlab}。
\item \textbf{自检（约 1 分钟）：}
\begin{lstlisting}
check_implementation
\end{lstlisting}
它会输出：解析梯度与有限差分的相对误差（应 $<10^{-5}$）、保密注水解的 KKT 检验、算法 2 的单调性、闭式速率与蒙特卡洛的对比。
\item \textbf{快速功能测试：}打开 \code{run\_all.m}，把第一行改为 \code{QUICK = true;} 后运行（每个点只用 3 个随机场景，几分钟内跑完，曲线较粗糙）。
\item \textbf{完整仿真：}\code{QUICK = false;}（默认），运行 \code{run\_all}。默认每个点平均 50 个随机场景。
实测（Octave 8.4，单线程）：图 1 约 1 分钟，图 2 约 0.2 分钟，图 3/6 约 45 分钟，图 4 约 22 分钟，图 5 约 18 分钟，图 7 约 17 分钟，图 8 约 26 分钟，
合计约 2 小时（MATLAB 一般更快；多开几个 MATLAB 会话分别运行不同的图即可并行）。也可以单独运行某一张图，例如
\begin{lstlisting}
prm = default_params();      % 读取默认参数
prm.numDrops = 20;           % 修改参数（这里减少随机场景数以加快速度）
fig3_essr_vs_power(prm);     % 只跑图 3（同时生成 AN 功率占比图）
\end{lstlisting}
\item 结果保存在 \code{results/} 文件夹：\code{.mat}（数据）、\code{.png}/\code{.eps}/\code{.pdf}（图），MATLAB 下还会保存 \code{.fig}。
只想重画图（不重新仿真）时运行 \code{replot\_all}。
\end{enumerate}

\subsection{算法 2（\code{ao\_optimize.m}）的内部逻辑}
\begin{enumerate}
\item 初始化位置 $\bt^{(0)}$（UPA 或随机可行位置），调用 \code{power\_opt} 得到 $(\mathbf p^{(0)},q^{(0)})$。
\item \textbf{位置更新}（\code{position\_sweep}）：对 $n=1,\dots,N$：
  \begin{enumerate}
  \item \code{grad\_F\_n} 计算 $\nabla_{\bt_n}F$（式 (48)）；
  \item \code{lin\_constraints} 生成 $\mathcal C$ 的盒约束和线性化间距约束 (51)；
  \item \code{proj\_polygon} 求解子问题 (52)：把 $\bt_n^{(\ell)}+\nabla F/\delta_n$ 投影到凸多边形；
  \item 回溯：若 $F(\text{新点})<\hat F_n(\text{新点})$（式 (49) 的二次下界），则 $\delta_n\leftarrow2\delta_n$ 重新求解；满足后接受新点（保证式 (53) 的单调性）。
  \end{enumerate}
\item \textbf{功率更新}（\code{power\_opt}，算法 1）：对 $q$ 做“粗网格 + 细网格”一维搜索，每个 $q$ 下用 \code{secrecy\_wf} 的保密注水 (38) 得到 $\mathbf p$；只有当目标值不下降时才接受新的 $(\mathbf p,q)$。
\item 若目标值的相对增量小于 \code{aoTol}，或达到 \code{aoMaxIter}，停止；否则回到第 2 步。
\end{enumerate}
由于每一步都不降低 $F$，目标值序列单调不减（图 2 可以验证）。

\subsection{保密注水（\code{secrecy\_wf.m}）}
给定 $q$，令 $\vartheta_m=\xi_m/(q\psi+\bar\sigma_e^2)$。$\eta_m\le\vartheta_m$ 的 LU 直接关断（$p_m=0$）；其余 LU 按式 (38)
\[
p_m(\nu)=\Big[\tfrac{2(\rho_m-1)}{\sqrt{(\eta_m-\vartheta_m)^2+4\eta_m\vartheta_m\rho_m}+\eta_m+\vartheta_m}\Big]^+,\quad \rho_m=\tfrac{\eta_m-\vartheta_m}{\nu\ln2},
\]
$\sum_mp_m(\nu)$ 关于 $\nu$ 单调递减，用二分法使之等于 $P_{\rm I}(q)=P_{\rm tot}-(N-M)q$。代码对网格上的所有 $q$ 同时二分（向量化），速度很快。

\subsection{蒙特卡洛评估（\code{mc\_rates.m}）}
每个样本生成 $\mathbf H=(\mathbf L+\tilde{\mathbf H})\mathbf B^{1/2}$ 与 $\mathbf g$，计算 $\mathbf G=\mathbf H^H\mathbf H$、$\mathbf u=\mathbf H^H\mathbf g$ 和 $\mathbf G^{-1}$（批量求逆），然后
\[
\gamma_m=\frac{p_m}{\sigma_m^2[\mathbf G^{-1}]_{m,m}},\quad
|\mathbf g^H\bar{\mathbf w}_m|^2=\frac{|[\mathbf u^H\mathbf G^{-1}]_m|^2}{[\mathbf G^{-1}]_{m,m}},\quad
\mathbf g^H\mathbf P_{\mathbf H}^\perp\mathbf g=\|\mathbf g\|^2-\mathbf u^H\mathbf G^{-1}\mathbf u,
\]
即式 (12)、(13) 的精确值（不需要显式构造 $N\times N$ 投影矩阵）。ESSR $=\sum_m[\bar R_m-\bar R_{e,m}]^+$。

\section{各图说明与预期现象}
\begin{description}
\item[图 1（\code{fig1\_accuracy}）] 固定功率分割 $\alpha=0.5$，UPA 与随机 MA 位置两种布局；横轴为发射 SNR（1a/1b）或莱斯因子 $\kappa=\kappa_e$（1c/1d）。
预期：Eve 的闭式近似（命题 1）与蒙特卡洛高度吻合；LU 的闭式近似（引理 1，现有结果）是偏保守的下界型近似，其差距随 $\kappa$ 增大而增大，但对两种布局几乎相同（即对位置不敏感，支撑注 1）。
\item[图 2（\code{fig2\_convergence}）] 算法 2 的目标值随迭代单调上升并收敛；不同初始化收敛到相近的值；命令行同时打印最终解的蒙特卡洛 ESSR。
\item[图 3、图 6（\code{fig3\_essr\_vs\_power}）] ESSR 与 AN 功率占比 $(N-M)q/P_{\rm tot}$ 随发射 SNR 的变化。预期：所提 MA 方案最好；无 AN 的方案在高 SNR 饱和；MA 的 AN 占比低于 FPA（AN 节省效应，注 4）。

\section{常见修改}
\begin{itemize}
\item \textbf{改系统参数：}例如
\begin{lstlisting}
prm = default_params();  prm.N = 6;  prm.kappa_dB = 5;
fig3_essr_vs_power(prm);
\end{lstlisting}
\item \textbf{不同用户不同路损：}\code{prm.beta\_dB = [0 -5 -10];}（长度须等于 $M$）。此时每用户功率分配相对等功率的增益更明显。
\item \textbf{改扫描范围：}在对应 \code{figX\_*.m} 中修改 \code{Pvec}、\code{Dvec}、\code{Avec}。

\item \textbf{Octave 用户：}无图形界面时先执行下面两行，并安装 Ghostscript 以导出 EPS/PDF：

graphics_toolkit('gnuplot');  set(0, 'defaultfigurevisible', 'off');
\end{lstlisting}
\end{itemize}
